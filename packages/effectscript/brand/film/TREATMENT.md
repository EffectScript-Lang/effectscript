# Introducing EffectScript — film treatment

A 160-second launch film made entirely from code: Blender (Python) for the 3D
shots, a Skia/NumPy compositor for typography, code morphs and shaders, GPT
Image 2.5 stills for the photographic world, and a score synthesised sample by
sample in NumPy. ffmpeg assembles the result. Nothing is hand-keyed.

**Story:** every idea starts as one line. Effect gives that line superpowers,
then buries it in ceremony. EffectScript gives the line back.

**Format:** 1920×1080, 30 fps, 160.0 s (4800 frames), stereo 48 kHz.
**Palette:** brand only — ink `#09090B`, tile `#18181A`, line `#27272A`,
muted `#71717A`, subtle `#A1A1AA`, white. All photography is true monochrome.
**Type:** Inter Display Bold for headlines, Inter for body, JetBrains Mono for
code and `// LABELS`.

## Tempo grid

120 BPM, 4/4. One beat = 0.5 s, one bar = 2.0 s, 80 bars. The opening and the
3 AM section are felt in half time (a piano phrase every bar or two); the
technical section drives on every beat. Every cut below lands on the grid.

All on-screen words, in order. Nothing else is written on screen.

1. `// every idea starts as one line` → `getUser(id)`
2. You found Effect.
3. Typed errors. · Retries. · Resources that never leak. · Concurrency that just works.
4. It felt like a superpower.
5. Then you wrote it down.
6. You wanted reliability. · You got ceremony.
7. What if the language · just understood?
8. Introducing → EffectScript lockup → TypeScript with Effect built into the language.
9. Feature labels: `// 01 EFFECT FUNCTIONS` `// 02 TYPED ERRORS` `// 03 TRY / CATCH`
   `// 04 PIPELINES` `// 05 SERVICES` `// 06 RESOURCES` `// 07 MATCH`, each with one caption.

12. All of Effect. · None of the ceremony.
13. Lockup · `npm i effectscript` · Built on Effect

## Brand rules that apply

Never show the Effect logo. Say "built on Effect", never "official". The mark
is white on black, never tinted; in 3D it is pale concrete or emissive white.
Show the full lockup at the first reveal and at the end.
